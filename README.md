# 🔐 AI/ML Security Lab

Explore AI and ML security by simulating attacks, analysing their impact, and building defenses with Python.

This repository contains practical Python labs exploring how machine learning and AI systems can be manipulated, where security weaknesses can appear, and how defensive techniques can help build more robust systems.

Each lab follows a hands-on security approach:

**🟢 Baseline → 🔴 Attack → 🔍 Observe → 🛡️ Defend → ✅ Verify**

---

## 🎯 What Is This?

**AI/ML Security Lab** is a practical Python series focused on exploring security concepts across machine learning and modern AI systems.

Rather than only explaining vulnerabilities theoretically, the labs use controlled Python experiments to demonstrate how security weaknesses can affect models and AI applications.

The series focuses on understanding both sides of AI security:

- How a system behaves normally
- How it can be manipulated or affected
- What impact the security issue creates
- How defensive techniques can be applied
- Whether those defenses improve the system's security

---

## 🔬 How The Labs Work

Each lab follows a security-focused experimental workflow.

### 🟢 Build the Baseline

Establish how the model or AI application behaves under normal conditions.

### 🔴 Simulate the Attack

Introduce a controlled security threat, manipulation, or vulnerable condition.

### 🔍 Observe the Impact

Analyse how the attack affects predictions, data, model behaviour, or application security.

### 🛡️ Apply the Defense

Implement defensive controls designed to reduce the identified risk.

### ✅ Verify the Defense

Test the system again and observe whether the defensive measures improve its security.

## 🚀 How To Use?

1. Clone the repository:

```bash
git clone https://github.com/abhijithwarrier/AI-ML-Security-Lab.git
```

2. Navigate into the repository:

```bash
cd AI-ML-Security-Lab
```

3. Install the dependencies required for the lab you want to explore.

4. Start Jupyter Notebook:

```bash
jupyter notebook
```

5. Open a lab notebook and execute the cells sequentially.

The notebooks include Markdown explanations alongside the Python code, allowing you to follow the security experiment from the initial setup through attack simulation and defense verification.

## 💡 Why This Series?

AI and machine learning systems are increasingly being integrated into real-world applications.

But good model accuracy or intelligent behaviour does not automatically mean that an AI system is secure.

Models and AI applications can encounter risks involving manipulated inputs, untrusted data, exposed information, unsafe model behaviour, and weaknesses in the applications surrounding them.

**AI/ML Security Lab** explores these risks through practical Python experiments while introducing defensive thinking alongside AI development.

The goal is not simply to make AI work — but to understand how to make AI systems **safer, more robust, and more trustworthy**.
